# Universal AI Agent - APK с локальными нейронками

Настоящее Android приложение, работает **полностью оффлайн на телефоне**, без компа и без сервера.

### Что внутри

- 🤖 **Режим АГЕНТ** - много нейросетей работают вместе как на Linux. Можно выбирать какой ИИ использовать
- 🎬 **Видеоредактор с ИИ** - локальная нейронка сама монтирует видео (режет тишину, выбирает лучшие дубли, собирает по смыслу)
- ⏰ **Планировщик задач** - ставит задачи на будущее, с уведомлениями
- 📦 **Все модели с Hugging Face**, качаются при первом запуске, потом оффлайн

### Модели (все локальные)

| Модель | Размер | Откуда | Зачем |
|--------|--------|--------|-------|
| Whisper Tiny | 39MB | `Xenova/whisper-tiny` | Слушает речь, ищет тишину и "эээ" |
| CLIP ViT | 150MB | `Xenova/clip-vit-base-patch32` | Видит кадры, оценивает качество |
| Moondream2 | 400MB | `Xenova/moondream2` | Описывает что на видео |
| Llama 3.2 3B | 2GB | `mlc-ai/Llama-3.2-3B` | Директор, решает как монтировать |
| FFmpeg | 30MB | `ffmpeg.wasm` + `ffmpeg-kit` | Режет и склеивает |

### Как собрать APK с телефона (без компа)

#### Вариант 1 - через GitHub (5 минут, рекомендую)

1. Зарегайся на github.com с телефона
2. Создай новый репозиторий `ai-agent-apk` (Public)
3. Залей все файлы из этой папки (кнопка Upload files)
4. Открой вкладку Actions - там уже запустится сборка
5. Через 10-15 минут скачай APK из Artifacts: `universal-ai-agent-apk`

#### Вариант 2 - через Termux

```bash
pkg install nodejs git openjdk-17 -y
git clone https://github.com/ТВОЙ_НИК/ai-agent-apk
cd ai-agent-apk
npm install
npm run build
npx cap add android
npx cap sync
cd android && ./gradlew assembleDebug
# APK в android/app/build/outputs/apk/debug/app-debug.apk
```

### Как работает режим АГЕНТ

Ты выбираешь какие ИИ включить:

- Vision Agent - смотрит
- Audio Agent - слушает
- Director Agent - планирует

Они общаются через JSON и вместе решают задачу. Как на Linux, только на телефоне.

### Как работает видеоредактор

1. Выбираешь видео/фото из галереи
2. Жмешь "ИИ Смонтируй"
3. ИИ сама: описывает кадры, транскрибирует речь, вырезает тишину, выбирает лучшие дубли, собирает с эффектами (crop 88% linear, zoom, 16:9 24fps)

### Планировщик

- Ставишь время: "смонтируй завтра в 9:00"
- WorkManager + LocalNotifications
- Приходит уведомление когда готово

Бесплатно, оффлайн, без сервера, с телефона.

# Как собрать APK с телефона без компа - пошагово

Ты на телефоне, компа нет. Делаем все с телефона за 5 минут.

## Шаг 1: Зарегайся на GitHub

1. Открой https://github.com в браузере телефона
2. Нажми Sign up
3. Введи почту, пароль
4. Подтверди почту

## Шаг 2: Создай репозиторий

1. Нажми + справа вверху -> New repository
2. Название: `ai-agent-apk`
3. Выбери Public
4. Нажми Create repository

## Шаг 3: Залей файлы проекта

1. В репозитории нажми "uploading an existing file" или Add file -> Upload files
2. Выбери ВСЕ файлы из папки `ai-agent-apk`:
   - package.json
   - capacitor.config.json
   - vite.config.js
   - index.html
   - src/app.js
   - src/models/README.md
   - .github/workflows/build-apk.yml
   - README.md
   - КАК_СОБРАТЬ_С_ТЕЛЕФОНА.md
3. Нажми Commit changes

Важно: сохрани структуру папок! src/app.js должен быть в папке src

## Шаг 4: Подожди сборку

1. Открой вкладку Actions в репозитории
2. Там уже запустился Build Universal AI Agent APK
3. Жди 10-15 минут пока не станет зеленая галочка ✅
4. Нажми на сборку -> внизу Artifacts -> universal-ai-agent-apk
5. Скачай - внутри app-debug.apk (примерно 10-15MB без моделей, модели скачаются внутри приложения)

## Шаг 5: Установи

1. Открой скачанный APK
2. Разреши "Установка из неизвестных источников" если попросит
3. Установи приложение AI Agent
4. Открой - при первом запуске скачает модели с Hugging Face (нужен Wi-Fi, ~2.6GB если все, или 70MB в lite режиме)

## Что внутри APK

- 4 вкладки: АГЕНТ, МОНТАЖ, ПЛАН, МОДЕЛИ
- АГЕНТ: включаешь какие ИИ нужны (Vision, Audio, Director, CLIP), они работают вместе
- МОНТАЖ: выбираешь видео/фото, жмешь ИИ СМОНТИРУЙ - все локально через FFmpeg
- ПЛАН: планировщик задач через WorkManager, работает в фоне
- МОДЕЛИ: выбираешь какие модели ставить с Hugging Face

Все бесплатно, оффлайн после загрузки, без сервера.

## Альтернатива через Termux (если не хочешь GitHub)

1. Установи Termux из F-Droid (не из Play Market)
2. Открой Termux:

```bash
pkg update && pkg upgrade -y
pkg install nodejs git openjdk-17 -y
git clone https://github.com/ТВОЙ_НИК/ai-agent-apk
cd ai-agent-apk
npm install
npm run build
npx cap add android
npx cap sync
cd android
./gradlew assembleDebug
```

3. APK будет в `android/app/build/outputs/apk/debug/app-debug.apk`
4. Скопируй: `cp android/app/build/outputs/apk/debug/app-debug.apk /storage/emulated/0/Download/`

## Проблемы

- Actions падает? Проверь что залил все файлы с правильной структурой
- APK не ставится? Включи в настройках Android "Установка из неизвестных источников"
- Модели не грузятся? Нужен интернет при первом запуске, потом оффлайн
- Телефон слабый? В приложении вкладка МОДЕЛИ -> включи только Whisper+FFmpeg (70MB)
